A chess engine in under 4 KB of Python: alpha-beta with a transposition table, null move, late move reductions and quiescence, under a fixed node budget so every move is deterministic. main.py is an LZMA-packed build of the engine.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 main.py
```
